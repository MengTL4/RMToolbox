# 界面与交互优化设计

状态：整体方案已获确认，实施与回归验证完成。

## 已确认方向

- 同时优化视觉层级与操作流程。
- 采用清爽、紧凑的桌面工具风格。
- 保留现有功能与深色、浅色主题。
- 顶部统一选择当前游戏，修改器、数据、存档和控制台共同跟随；断开时保留选择并明确提示，不自动改选其他游戏。
- 主导航保留游戏库、修改器、数据、存档；控制台与日志归入高级工具，场景修复默认收起。
- 数值输入和加减按钮均先调整草稿，点击“应用”或按 Enter 提交；开关点击即生效，操作结果明确反馈。
- 游戏连接成功后保留当前页面，由用户点击“打开修改器”选中该游戏并进入功能页。
- 连接等待显示真实状态并阻止重复操作；失败原因与重试入口显示在对应游戏处。
- 未提交数值按游戏保留在本次窗口中，切回来可以继续编辑并对照最新实际值，绝不自动提交。

## 当前界面观察

依据当前 UI 源码及仓库已有的游戏库、修改器和数据页截图；截图用于布局参考，尚未验证当前运行窗口。

- 修改器与数据页共享所选游戏，存档页和控制台另有自己的选择，跨页操作的目标可能不一致。
- 修改器中的常用修改、战斗操作、场景跳转与修复工具同时展开，主次关系不明显。
- 数值输入需要“应用”，通用加减按钮却直接提交，存在两套提交规则。
- 数据页同时展示九个分类、锁定配置操作和回写帧数，工具栏可进一步分层。
- 游戏库卡片将引擎、保护级别和文件路径放在显著位置，用户需要的可操作状态可以更突出。

## 实施范围

1. 界面框架：统一当前游戏位置和连接状态；主导航突出常用入口，高级工具分组收纳。
2. 游戏库：突出名称、可操作状态与一个主操作；路径、引擎和诊断信息降为辅助信息。连接成功后的主操作是打开修改器，停止游戏作为次操作。
3. 等待与失败：同一游戏的启动、附加和停止互斥；仅显示能够从实际过程确认的状态，不编造百分比或剩余时间。涉及接管重启时明确表达实际行为，保留既有运行策略。
4. 修改器：常用开关、金钱和倍率优先展示；战斗功能保持可发现，场景修复默认收起。统一数值草稿、提交与结果反馈。
5. 数据与存档：整理分类和工具栏层级，明确区分运行中数据编辑与存档文件、备份管理；统一当前游戏和未连接状态。
6. 视觉：统一字体层级、间距、控件尺寸和色彩用途，提高辅助文字可读性；保留深浅主题，避免大面积装饰占用操作空间。

## 验收范围

- 覆盖当前默认窗口 1180×800 与最小窗口 900×640，检查深浅主题、列表滚动、工具栏和弹窗是否挤压或溢出。
- 覆盖无游戏、单游戏、多游戏、连接中、失败和断开状态；切页或断开不能悄悄改变操作目标。
- 检查在 A、B 游戏间切换时，草稿、请求结果与实际数据均对应正确游戏；断开后不得提交修改。
- 检查加减仅改草稿、Enter/应用提交、开关即时生效；成功与失败反馈必须区分，失败不得伪装成已生效。
- 检查连接过程中重复点击互斥、连接成功不抢页面、进入修改器选择正确游戏。
- 完成界面构建、适当的交互回归与 GUI 检查；界面验证使用受控数据，不以真实游戏改写进度作为默认验收方式。

## 实现与验证入口

- 当前游戏统一由页头选择，断开时保留选择与草稿；请求结果和确认框按选择时的上下文隔离。
- 草稿以游戏与字段标识保存；物品、变量和角色区分具体条目。Essentials 角色额外使用运行中对象身份，避免队伍位置变化后复用其他成员的草稿；敌方 HP 草稿在新战斗时重新开始。
- 存档树在切换游戏前保存编辑文本，重新拉取仍保留原有放弃修改确认。
- 游戏库按状态展示主操作，启动、附加和停止互斥；接管重启和结束游戏明确说明实际行为。
- 游戏库常驻说明两种注入方式：由工具箱“启动并注入”，或用户先打开游戏后“附加到运行中”。附加按钮使用清晰的次级按钮样式，特殊游戏仍保留接管重启说明与能力限制。
- `node tools/test-ui-interactions.mjs` 使用真实 Vue、页面逻辑和 store，替换主机与游戏响应，验证选择、草稿、提交、旧请求、断开重连和互斥。
- `npm run test:ui-browser` 使用生产页面脚本与组件库，在受控数据下检查四个主页面、深浅主题、两种窗口尺寸和点击流程。需要 Node 22+ 与 Chrome，可用 `CHROME_PATH` 指定浏览器；截图写入 `runtime/screenshots/ui-review/`。
- 浏览器验证不加载本地主机模块，不访问游戏目录，不启动或修改真实游戏。

最终验证通过：16 组页面/主题/尺寸渲染、浏览器点击流程、完整 `npm test`、GUI 与 bridge 构建、Ruby 语法检查、`git diff --check`。RGSS3 归档的真实样本用例因未提供样本沿用原有跳过规则；本轮未进行真实游戏冒烟。
