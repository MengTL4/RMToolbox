- 在“数据 → 地图”扩展地图事件与事件迷你地图；“事件解释器”使用独立子页。
- 首版以 MV/MZ、XP/VX/VX Ace 全部现有引擎为目标，逐项核实能力，明确显示实际不支持的操作。
- 沿用统一“当前游戏”、断线保留选择和按游戏隔离状态的现有规则。
- 首版完成当前地图的事件列表、搜索/定位、传送、迷你地图及从事件进入指令查看；保留现有跨地图坐标传送。
- 全地图事件检索、调用链分析和路线规划不纳入本轮。
- 迷你地图采用可缩放网格、玩家/事件标记和通行信息，不还原游戏地形图块。
- “事件解释器”首版为只读事件阅读器，展示中文指令说明、分支层级、条件和参数，覆盖地图事件与公共事件；不包含暂停、单步或跳过执行。
- 到事件的普通传送默认选取事件旁的可通行空格；无合适落点时给出原因，另提供明确的强制到事件坐标操作。
- 迷你地图在工具箱内以大弹窗打开，支持缩放、拖动和跟随玩家。点击选中，明确点击“传送”才改变游戏状态。
- 地图页或迷你地图可见时每秒刷新玩家与事件位置；地形通行按地图缓存，可手动重读。换地图清除旧选点，断线停止刷新与操作。
- 阅读器可查看地图事件的所有页，标记生效页、页条件及可读取的当前值；也支持公共事件。指令按分支缩进，可搜索；脚本和插件指令显示原文，未知指令保留编号和原始参数。
- 增加当前正在执行事件的只读入口：列出可识别的执行中事件，选择后定位当前指令；无法识别时明确说明，不提供执行控制。
- 阅读正文保留本次快照；同游戏换地图或事件换页时标出来源和“内容已过期”，手动重读才替换。切换游戏清空当前阅读视图。
- 正常传送只在地图可操作且没有对话、战斗或转场时执行；强制坐标传送需确认，只放宽落点通行限制，不能绕过断线、旧地图或剧情忙碌限制。

- `app/gui/src/views/DataMapView.vue` 已有地图列表、坐标传送、当前地图事件和独立开关区域。

- 当前“公共事件”页仅提供列表和运行入口，不能等同于事件解释器。

### 关键验收场景

- 列表与迷你地图选中同一个事件，点击地图不自动传送；普通传送不与目标事件重叠，无法找到落点时解释原因。
- 同格多个事件可区分；隐藏、无生效页、已消除或已不存在的事件不能被误认为仍可操作的事件。
- 传送过程中切游戏、换地图、事件移动/消失或进入对话/战斗时，拒绝过期/不适用的操作；前端与游戏端均核验。
- 切页或隐藏迷你地图后停止无用轮询，慢请求不堆积；迟到回复不覆盖当前游戏/地图。
- 大地图按块处理通行数据，局部读取失败显示未知，不能伪装成“可通行”；移动事件占位不能只依赖静态地形缓存。
- 事件页条件与分支条件区分展示；只读取，不求值任意脚本或插件条件。未知条件明确显示未知。
- 指令文本支持长对话、选择项、嵌套分支、循环、公共事件调用、脚本续行、移动路线和未知指令；不执行脚本来生成说明。
- 正文快照不被轮询替换；运行位置作为单独只读标记，执行结束或身份变化时清楚提示。
- 保留原有公共事件运行入口和其他既有功能；只读解释器不新增运行、编辑或跳过指令能力。

## 实现结构

- `runtime/bridge/src/parts/65-event-tools.js` 与 `runtime/rgss-bridge/bridge.rb` 实现同一协议。RGSS 请求字段保持扁平，兼容原有 Ruby 1.8 JSON 参数解析器。
- `map.inspect` 提供当前地图身份、玩家/事件坐标、生效页及忙碌原因；`map.grid` 每块最多 2048 格，按方向位保存通行状态（VX 使用步行通行位），`-1` 表示无法判断。
- `map.move` 校验地图和事件身份、忙碌状态及落点。普通事件传送选邻接空格；强制传送仍需确认并执行身份/场景检查。旧坐标传送增加场景检查，保留跨地图入口。
- `events.read` 每次最多 300 条，读取时携带版本；后续分块版本变化则拒绝拼接。`events.status` 单独核对正文版本及执行位置，`events.running` 枚举可识别的主、并行和子解释器。
- `app/gui/src/state/event-tools.js` 统一管理可见性轮询、地图缓存、游戏切换隔离、读取竞态和快照；`event-format.js` 只格式化数据，不运行脚本。
- 大地图使用 Canvas 绘制可见格子，不为每格创建 DOM；最多读取 400 万格。事件最多 2 万条指令，参数设有深度、数组长度和字符串长度上限，超出时保留限长表示。搜索针对已读取指令，长事件可分批继续读取。
